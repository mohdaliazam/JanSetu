# Scope and release boundaries

The two-hour plan is an execution budget, not permission to claim omitted track features exist. Choose a release target explicitly using the harness CLI. Default target is `demo`; `full` includes all demo tasks and track-completion extensions. Never silently switch down from full to demo.

## Demo must-have: P00-P10

Multilingual text intake (Hindi and English); secure server-side Gemini extraction; visible correction/confirmation; deterministic grouping; district/locality filters; service-gap and planned-investment context; transparent ranking; cited project briefs; isolated synthetic workspaces; persistent storage; error handling; live deployment; source package; 10-12 slide deck; 3-5 minute video and submission checklist.

The demo uses two fictional localities in each of three real district/state contexts. Records are synthetic and not representative statistics. A locality/category grouping is a coarse planning group, not proof that two complaints describe the same broken asset.

## Track-completion requirements: X01-X04

- X01: voice intake, accessible transcript confirmation, validated Hindi and English transcription; no unsupported browser silently disabled.
- X02: one actual messaging channel adapter with verified inbound webhook, deduplication and the same intake pipeline; sandbox acceptable if accurately labelled.
- X03: documented public-data import, geography crosswalks, missingness and freshness handling, broader load testing and an interoperability export contract.
- X04: role-based production access, privacy/retention controls, auditability, licensed public-good distribution and deployment hardening. This is a validated pilot profile, not nationwide production certification.

These items have explicit plans and acceptance tests. If time only permits the demo, list the remaining track gaps in the pitch and submission. The screenshot's voice/messaging/national-scale ambition must not disappear from the blueprint.

## Nice-to-have after the active target's gates

Map with an accessible table alternative, more languages, downloadable PDF briefs, comparison snapshots, richer illustrations. None should displace working Google AI or submission assets.

## Future beyond this blueprint's pilot target

Nationwide identity integration, legally binding government workflows, verified field surveys, multiple BRICS deployments, offline mobile apps, formal impact evaluation, nationwide resilience and procurement certifications. Document prerequisites; do not imply these can be validated in a hackathon.

## Explicit exclusions

No automatic allocation of public funds, predictive claims without validated models, personal profiles, Aadhaar collection, medical/legal advice, police dispatch, surveillance, paid map requirement, fabricated official statistics, or automatic publication of raw citizen messages.
